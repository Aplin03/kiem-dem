Chưa có bản đồ.
Trên máy tính: tool Nông trường → tab Cài đặt → Export CSV. Chép 2 file trees.csv và plots.csv (thư mục exports) sang điện thoại rồi mở ở đây.

3. Xuất kết quả (CSV cho tool)

Trên máy tính: tool → tab Thiết lập lô → Import cây từ CSV → chọn file này. Nên bấm Tạo backup (tab Cài đặt) trước khi Import.

4. Ảnh vệ tinh offline

Khi đang có mạng (nên dùng Wi-Fi), tải sẵn ảnh vệ tinh khu vực các lô để ra vườn mất sóng vẫn xem được.
